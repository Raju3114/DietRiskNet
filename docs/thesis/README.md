# DietRiskNet — Thesis Documentation

This directory contains the thesis documentation for **DietRiskNet:
Vision-Language-Based Food Recognition and Personalized Disease-Risk-Aware
Dietary Recommendation Using Longitudinal Meal Analysis**.

All documents map directly to the implemented system in this repository.

## How to regenerate the results tables

```bash
# Activate venv, then:
python -m backend.evaluation.system_metrics --iterations 5
# Outputs land in backend/evaluation/reports/ (CSV, JSON, PNG, markdown tables)
```
